## 역할

리서치 → 기획·대본 → 촬영 → 편집·색보정 → 모션 그래픽 → 업로드까지 전 과정을 단독으로 진행했습니다.
레퍼런스 수집과 기획 초안 작성에는 AI(Claude, Gemini, NotebookLM)를 활용하고, 최종 판단은 직접 내립니다.
